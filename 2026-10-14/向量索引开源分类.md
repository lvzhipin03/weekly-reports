##### milvus
###### 简介
Milvus 是一个高性能、可大规模扩展的开源向量数据库，专为 AI 应用设计，用于高效组织和检索海量非结构化数据（如嵌入向量）。它采用 Go 编写分布式服务编排层、C++ 编写计算引擎，并支持 CPU/GPU 硬件加速。

特点如下：

+ 存算分离架构：计算节点与存储完全解耦，读密集和写密集负载可独立水平扩展。
+ 多种部署模式：支持 Kubernetes 原生分布式集群、Standalone 单机部署，以及嵌入 Python 使用的 Milvus Lite（通过 `pymilvus`，只支持 FLAT 索引）。
+ 丰富的索引：通过 Knowhere 库支持 HNSW、IVF、DiskANN 等向量索引。

向量引擎为：konwhere（c++），集成了 <font style="color:rgb(31, 35, 40);">FAISS, hnswlib, DiskANN</font>

查询执行引擎为：Segcore（c++）

###### knowhere 支持的索引类型
1. 稠密向量（dense）

| 类别 | 索引类型 |
| --- | --- |
| 暴力/精确 | FLAT |
| IVF 系列 | IVF_FLAT、IVF_FLAT_CC（支持并发读写）、IVF_PQ、IVF_SQ8、IVF_SQ_CC、IVF_RABITQ |
| ScaNN | SCANN、SCANN_DVR（基于 faiss::IndexScaNN） |
| 图索引 | HNSW、HNSW_SQ、HNSW_PQ、HNSW_PRQ |
| 磁盘索引 | DISKANN、AISAQ（KIOXIA 贡献，PQ 压缩 + I/O 优化） |


集成 faiss 的方式是，直接把源码 copy 到 thirdparty/faiss 目录下。在 faiss 更新时，人工手动进行合并。对 faiss 源码的更改也更多是添加新文件，这个目录是 faiss/cppcontrib。直接对源码的修改也用 konwhere-specific 标注出来了。



2. 二进制向量

BIN_FLAT、BIN_IVF_FLAT、MINHASH_LSH（Jaccard 相似度），以及 HNSW 也支持 binary 数据类型。

3. 稀疏向量

SPARSE_INVERTED_INDEX、SPARSE_WAND（以及 _CC 并发变体），支持 IP 和 BM25。

4. GPU 索引（需 with_cuvs 编译选项）

GPU_CUVS_BRUTE_FORCE、GPU_CUVS_IVF_FLAT、GPU_CUVS_IVF_PQ、GPU_CUVS_CAGRA，以及别名 GPU_BRUTE_FORCE、GPU_IVF_FLAT、GPU_IVF_PQ、GPU_CAGRA。
